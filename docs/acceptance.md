# 0.2.0 验收记录

2026-11-21 · macOS、Obsidian 1.15.1（安装器 1.13.7）、Live Preview。运行目标为 `Obsidian AI Coding` 测试 Vault，已确认加载 `zoom-into-section-peng` 0.2.0，三个安装产物与构建输出逐一匹配。测试设置结束时为 **Right Split Pane**。

## 对照与样例

- 部署前用 `Folding baseline 0.2.md` 复核 0.1.0。A 折叠时打开右侧详情，Outline Tab 的折叠、光标和滚动读数均保留，关闭后新开普通标签仍折叠 A。原生 0.1.0 产物保存在测试区域的 `.rollback/0.1.0/`，回退时可核对 manifest 与哈希，再定向安装这三个文件。
- 测试使用原有 `Section boundaries.md` 的结构用例、短样例 `Folding baseline 0.2.md` 和新增的 923 行 `Long outline 0.2.md`。长样例从项目根目录运行 `node tests/fixtures/long-outline.mjs` 生成，图片使用专用测试目录已有的 `zoom-test-image.png`。测试时的文件与生成器输出逐字节一致。

## 结果

| 项目 | 实测结果 |
|---|---|
| 静态检查 | `npm run build`、`npm run lint` 和 `npm test` 通过。10 项测试覆盖 Section 边界、祖先路径、同名节点、注释、代码中的字面百分号和同一行嵌套标记。 |
| 设置、位置与去重 | 原生设置页渲染了下拉框，经模拟下拉变更事件保存到插件配置，定向重载后读回正确。通过真实修饰键鼠标输入验证两种默认位置。旧命令 ID 和两个新命令均通过。两个源标签组各自打开同一 Section，右侧专用组关闭后可重建。跨组移动用 Workspace 重挂接探针验证，移动后的普通标签恢复原生标题。 |
| 面包屑与退出 | 真实鼠标与键盘输入均可返回父层。同组已有父标签时复用，子标签保留。右侧测试还覆盖原地扩大范围、点击笔记名显示全文、切换阅读视图、定向重载和停用后的显示恢复。另在专用测试笔记中验证父标题及文件改名、当前 node 删除和撤销。 |
| 窄栏与长笔记 | 长样例最深路径含六段面包屑，窄栏产生横向滚动，当前段保持在右端可见。同组切回长笔记 Outline Tab 后，光标和滚动位置与触发前相同。一次打开并轮询确认完成用时约 1.5 秒，此数值包含 CLI 调用与轮询。 |
| 原文保护 | 两种位置分别通过真实键入、`⌘A`、落盘读回、撤销和边界删除。扩大范围后复查选择范围，模拟多行粘贴后以真实按键验证撤销、重做与落盘恢复。测试原文恢复到编辑前的字节内容。 |
| 折叠与冷重启 | 两种位置同时存在时，新开的普通标签仍折叠 A。分别关闭两种位置的 Zoom Tab、停用插件和定向重载后，复核原生折叠。保留两种位置的 Zoom Tab，先关闭 Outline Tab 再退出并重启 Obsidian。确认进程已替换，打开普通标签后折叠记录与原文均和对照一致。 |

阅读视图有一项原生边界行为。在无聚焦的普通标签中切到阅读视图后、渲染完成前立即关闭，Obsidian 1.15.1 本身也可能清空该文件的原生折叠记录。此项用普通标签对照复现；Zoom 关闭与冷重启验收使用 Live Preview。Recursive Fold 组合、物理拖动及其他平台未实测。鼠标、键盘使用 Obsidian 渲染器的 CDP 输入，配置持久化与笔记保存均检查了文件。

## 重跑步骤

1. 在测试 Vault 打开短样例，确保 A 折叠、B 展开，记录 Outline Tab 的状态。保留原有测试图像。首次设置变更前记录配置值，验收结束后恢复。
2. 将默认位置设为同组，在 B 上运行原命令。再用右侧命令打开同一 B，重复两次以验证各自的查重。切回右侧默认值，用命令和 `⌘`＋点击分别检查路由。始终保留一页普通 Outline Tab 作为折叠对照。
3. 从 Outline Tab 打开 B1。在一组内让列表父 Section 尚未打开，验证点击父层后原地扩大范围。在另一组预先打开父标题，验证激活已有父标签。点击笔记名，确认当前标签恢复全文与原生标题。对长样例最深处重复打开与切层。
4. 在两种位置分别选中、输入、撤销并试删 Section 边界。扩大范围后复查选区，在测试文本中粘贴多行并撤销和重做。对比原文，然后分别检查关闭、重载与停用。最后在安全的单测试 Vault 会话中保留两种 Zoom Tab，关闭 Outline Tab 后冷重启，打开新普通标签核对原文和折叠。

# 0.1.0 开工与验收记录

2026-11-21 · 测试环境为 macOS 和 Obsidian 1.15.1（安装器 1.13.7），Node.js 22.23.1、npm 10.9.8。源码从官方 Sample Plugin 提交 `07ceb81d1fb3384af611ebf665a1ec42a7e5926d` 起步。插件 ID 为 `zoom-into-section-peng`。部署目标为 `Obsidian AI Coding` 测试 Vault。

## 测试样例与原生基线

样例在测试 Vault 的 `_PluginTests/zoom-into-section-peng/`。

| 文件 | 预期 |
|---|---|
| `Folding baseline.md` | A 标题保持折叠，B 标题保持展开。A 的 Section 含 Folded list 和 A1、A2，到 B 前为止。 |
| `Section boundaries.md` | Chapter A 包含下级标题。其 Summary 分支包含后续段落、图片、公式、嵌套列表和代码块，到 Neighbor A 前为止。Chapter B 下的同名 Summary 是另一分支。代码块中的标题及列表示例不作为入口。 |
| `zoom-test-image.png` | 第一处 Summary 内的本地图片样例。 |

用两个普通 Markdown 编辑器打开同一测试文件。两边最初都恢复了 A 的原生折叠。在普通右侧分栏展开 A 后，左侧 A 仍折叠，但原生保存记录变为空，新开的普通标签显示 A 已展开。恢复基线后，停用本插件并冷重启，普通标签重新读到 A 的折叠。实测由此分别检查**视图的显示状态**和**跨标签、跨进程可恢复的状态**。

## 结果

| 项目 | 证据与结果 |
|---|---|
| 静态检查 | `npm run build`（含 TypeScript 检查）、`npm run lint`、`npm test` 均通过，6 项自动化测试覆盖范围识别、节点身份映射及编辑边界。 |
| 安装和重载 | CLI 已核对到测试 Vault；读取到启用和运行中的插件。源码构建产物与安装副本的 `main.js` 哈希一致。 |
| 命令与折叠隔离 | 通过已注册命令打开 A，Zoom Tab 完整展开，Outline Tab 仍折叠。关闭 Zoom Tab 后，普通标签恢复 A 的折叠。两个 Zoom Tab 同时打开时，新开的普通标签也恢复 A 的折叠。 |
| 鼠标与多个标签 | 通过 Obsidian 渲染器的鼠标输入验证 `⌘`＋标题折叠箭头和列表行的折叠标记。两篇 Source Note 的四个 Zoom Tab 进入同一个 Split Pane。重复触发同一 Section 激活已有标签，两个同名 Summary 各有独立标签和行号。 |
| 内容与保存 | Live Preview 中观察到样例图片和公式。向 Obsidian 界面发送键盘输入，验证 `⌘A` 选中 Section、键入保存到 Source Note、撤销和边界删除。多行粘贴通过模拟剪贴板事件验证。另以内部分派探针验证无过滤的越界撤销交易被拦截。 |
| 目标变化 | 对 Summary 改名，标签更新，另一处同名 Summary 保持原目标，所有同源编辑器读到相同文档。通过真实键盘输入删除 B 的入口标题后，Zoom Tab 回到完整笔记，撤销时恢复标题并保留 A 的存储折叠。 |
| 冷重启 | 对照和插件场景都核对了 Obsidian 进程替换。插件场景先关闭 Outline Tab，保留两个 Zoom Tab，再冷重启。普通标签读回与原生基线一致的 A 折叠及原文。 |

界面输入证据来自 Obsidian 官方 CLI 的 CDP 输入与 DOM 回读。保存通过 Vault 文件回读核对。冷重启前确认只有测试 Vault 已打开且没有待保存的 Markdown 编辑。组合启用 Recursive Fold、其他平台、Canvas 和个人长笔记尚未实测。

## 重跑顺序

1. 打开短样例，手动折叠 A，保留 B 展开。在 A 上运行 **Open section in zoom tab**。核对左右显示和普通新标签的折叠。关闭 Zoom Tab 并重开 Source Note。
2. 在 A 和 B 分别打开 Zoom Tab，重复打开 A。打开长样例的两处 Summary，核对 Split Pane、标签数、行号和图片公式。
3. 在 Zoom Tab 实际输入、撤销、按 `⌘A`、尝试在 Section 边缘删除。核对源文件差异；删除 B 的标题后，确认回到完整笔记并撤销。复核普通标签仍恢复 A 的折叠。
4. 保留两个 Zoom Tab，关闭 Outline Tab。确认测试 Vault 没有未保存编辑后退出并重启应用，检查新的普通标签和源文件。
